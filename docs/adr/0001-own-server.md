# ADR-0001. Собственная система на сервере больницы

Статус: принято.

## Контекст
Больнице нужен учет прихода и ухода персонала по лицу. Готовые решения либо требуют покупки терминалов и своего сервера (ZKTeco BioTime), либо узнают сотрудника только по карте (Saby), либо хранят данные за рубежом (Railer). Биометрия работников – особая категория персональных данных, ч. 5 ст. 18 Закона № 152-ФЗ требует хранить базы данных граждан РФ в России.

## Решение
Разработать веб-приложение, которое работает на сервере в локальной сети больницы. Терминал – браузер с веб-камерой.

## Последствия
Данные не покидают больницу. Сопровождение сервера, резервное копирование и обновления выполняет ИТ-служба больницы.
