# ADR-0006. Терминал – страница в браузере с ключом точки прохода

Статус: принято.

## Контекст
На входах больницы нужны недорогие терминалы, которые легко заменить.

## Решение
Страница `/kiosk/` открывается в любом браузере с камерой. Ключ точки прохода выдается администратором один раз, хранится в браузере терминала и передается в заголовке `X-Kiosk-Key`; в базе хранится только SHA-256 ключа.

## Последствия
Подходит любой планшет или монитор с веб-камерой. Браузер дает доступ к камере только по HTTPS (или на localhost), поэтому сервер работает за nginx с TLS.
