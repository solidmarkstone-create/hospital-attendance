# ADR-0002. Модульный монолит: распознавание отделено от веб-части

Статус: принято.

## Контекст
Модели распознавания быстро устаревают (AdaFace, QMagFace и др.). Веб-часть (роли, табель, журнал) меняется по другим причинам. Нагрузка небольшая: несколько обращений к терминалу в минуту.

## Решение
Один процесс Django. Распознавание вынесено в пакет `recognition`, который не импортирует Django и работает только с изображениями и векторами. Веб-часть вызывает его через `apps/attendance/engine_service.py`.

## Рассмотренные варианты
Микросервисы (сервис распознавания + сервис учета + очередь сообщений) – избыточно для больницы на 300 человек. Код распознавания прямо в представлениях Django – нельзя заменить модель и протестировать отдельно.

## Последствия
Модель меняется настройкой `FACE_*` без правки веб-части. Модуль покрыт отдельными тестами на заглушках.
