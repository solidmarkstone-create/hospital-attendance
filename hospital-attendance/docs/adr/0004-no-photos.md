# ADR-0004. Хранить только зашифрованный вектор, фотографии не хранить

Статус: принято.

## Контекст
Ч. 7 ст. 5 Закона № 152-ФЗ требует уничтожать персональные данные по достижении целей обработки. Для сравнения нужен только вектор признаков.

## Решение
Эталонные снимки читаются в память, по ним считается вектор, снимки отбрасываются. Вектор шифруется Fernet (AES-128-CBC + HMAC-SHA256), ключ – в переменной окружения `BIOMETRIC_KEY`, вне базы данных. Кадры с терминала не сохраняются ни при каком решении.

## Последствия
При замене модели распознавания сотрудников фотографируют заново. Копия базы без ключа не раскрывает биометрию.
